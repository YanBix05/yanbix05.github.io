# assets/ folder

This folder holds the two files you need to add yourself:

- **profile.jpg** — your photo. Once added, update the `<img>` source in
  `index.html` (hero section) from `assets/profile.svg` to `assets/profile.jpg`.
- **resume.pdf** — your actual CV/resume file, exported as a PDF. The
  "Download CV" button in the hero section already links to
  `assets/resume.pdf`, so the button will work as soon as you add the file
  here with that exact name.

`profile.svg` is a placeholder graphic included so the page looks complete
before you add your own photo — feel free to delete it once `profile.jpg`
is in place.
